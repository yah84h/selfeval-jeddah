# قائمة فحص الجودة (QA) — دليل التقويم المدرسي

نفّذها على نسخة مثبَّتة (Windows أو ماك) قبل تسليم أي إصدار.

## التثبيت وأول تشغيل
- [ ] المثبِّت يعمل، ويظهر اختصار على سطح المكتب وقائمة ابدأ.
- [ ] أول تشغيل يعرض شاشة «إعداد ملف المدرسة»؛ لا يقبل اسمًا أقل من حرفين.
- [ ] بعد الإنشاء تظهر لوحة التحكم باسم المدرسة ونسبة 0%.
- [ ] مجلد البيانات موجود (زر «مجلد البيانات» أسفل الشريط الجانبي يفتحه).

## رفع الشواهد
- [ ] «رفع شاهد» يفتح نافذة اختيار الملفات ويقبل تحديد عدة ملفات.
- [ ] السحب والإفلات على الوثيقة يرفع الملفات.
- [ ] ملف باسم عربي يُحفظ بنفس اسمه داخل `evidence/<المؤشر>/<الشاهد>/`.
- [ ] ملف مكرر الاسم يُحفظ باسم `(2)` ولا يستبدل القديم.
- [ ] ملف بامتداد غير مدعوم (exe) يُرفض برسالة واضحة.
- [ ] ملف أكبر من 50MB يُرفض برسالة واضحة.
- [ ] النسبة في الشريط الجانبي ولوحة التحكم تتحدث فورًا بعد الرفع.

## المعاينة والفتح
- [ ] PDF والصور تُعاين داخل التطبيق.
- [ ] Word/Excel/PowerPoint تُفتح بالبرنامج الافتراضي.
- [ ] «إظهار في المجلد» يفتح مستكشف الملفات على الملف.

## الحذف والاستعادة
- [ ] حذف ملف يطلب تأكيدًا داخل التطبيق (لا نافذة متصفح).
- [ ] الملف يظهر في «سلة المحذوفات» ويمكن استعادته إلى مكانه.
- [ ] الحذف النهائي من السلة يزيل الملف من القرص.
- [ ] حذف شاهد مخصص ينقل ملفاته إلى السلة.

## الشواهد المخصصة والتسميات
- [ ] إضافة شاهد غير مدرج يظهر بوسم «شاهد مخصص» ويُحسب ضمن الإجمالي.
- [ ] لا يُقبل شاهد مخصص مكرر أو مطابق لشاهد أصلي.
- [ ] تعديل المسمى يظهر المسمى الجديد مع «(الأصل: …)» ويمكن إعادته.

## التقرير
- [ ] «الناقص فقط» يخفي الوثائق المكتملة.
- [ ] «طباعة» تطبع التقرير فقط (بلا شريط جانبي).
- [ ] «حفظ PDF» ينتج ملفًا عربيًا سليمًا بالاتجاه الصحيح.

## النسخ الاحتياطي
- [ ] «نسخة احتياطية الآن» تنشئ zip في مجلد backups ويظهر في القائمة.
- [ ] «حفظ نسخة في مكان آخر» يحفظ في المسار المختار.
- [ ] استعادة بالدمج لا تكرر الملفات الموجودة وتضيف الناقص.
- [ ] استعادة بالاستبدال تعيد الحالة كاملة، وتُنشأ نسخة `pre-restore` قبلها.
- [ ] ملف zip عشوائي يُرفض برسالة «ليس نسخة احتياطية صالحة».
- [ ] النسخ التلقائي اليومي يعمل عند التشغيل ويُبقي العدد المحدد فقط.

## رمز القفل
- [ ] تفعيل الرمز يطلب التأكيد؛ بعد إعادة التشغيل يظهر قفل.
- [ ] رمز خاطئ يُرفض؛ الصحيح يفتح.
- [ ] إزالة الرمز تطلب الرمز الحالي.

## التحديث (الأهم)
- [ ] «التحقق من التحديثات» بلا إنترنت يعرض رسالة اتصال مفهومة.
- [ ] مع إصدار أحدث منشور: تظهر رقم الإصدار وملاحظاته → تنزيل بشريط تقدم → «تثبيت وإعادة التشغيل».
- [ ] بعد التحديث: اسم المدرسة والشواهد والنسب كما كانت، والإصدار الجديد ظاهر أسفل الشريط الجانبي.
- [ ] مجلد backups يحوي `pre-update_*.zip`.
- [ ] «فحص سلامة البيانات» لا يبلّغ عن ملفات مفقودة.

## إزالة البرنامج
- [ ] إزالة البرنامج من Windows **لا تحذف** مجلد البيانات (`deleteAppDataOnUninstall: false`).
